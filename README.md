Movie Trailer React App 🎬
A modern film platform built with React and Vite, allowing users to browse movies and watch trailers seamlessly.

🚀 About the Project
Movie Trailer React is a fast, responsive, and user-friendly web application. It integrates with YouTube to provide an immersive trailer-watching experience directly within the browser.

🛠 Tech Stack
This project leverages modern and high-performance libraries:

Frontend: React 18, Vite

Styling: Bootstrap 5

Routing: React Router DOM

HTTP Client: Axios

Video Integration: React YouTube

Icons: React Bootstrap Icons

📋 Features
Dynamic Content: Fetches movie data via API.

Trailer Streaming: Integrated YouTube player for trailers.

Responsive Design: Fully mobile-friendly layout using Bootstrap.

Optimized Build: Fast development and build process with Vite.

⚙️ Setup and Installation
Follow these steps to run the project locally on your machine:

Clone the repository:

Bash
git clone https://github.com/OmerSoyleyen24/Movie-Trailer-React.git
cd Movie-Trailer-React
Navigate to the frontend directory:

Bash
cd frontend
Install dependencies:

Bash
npm install --legacy-peer-deps
Start the development server:

Bash
npm run dev
The application will be available at http://localhost:5173
